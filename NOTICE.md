# Third-party code

`vendor/openidea-plugin/` is a verbatim copy of `sdk/rust/openidea-plugin/`
from [l0ng-ai/openidea](https://github.com/l0ng-ai/openidea) at tag `v0.1.39`,
distributed under Apache-2.0. It is vendored so this repository builds offline
and the released component can be reproduced from this source tree.

The plugin API (WIT) files under `vendor/openidea-plugin/wit/` and
`vendor/openidea-plugin/tests/api/released/` are part of the same SDK copy.

`LICENSE` is the Apache-2.0 text and applies to this plugin's own source in
`src/`.
